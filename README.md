# Fraternity

Broad, comparative situation research across protracted refugee/displacement
crises — building the evidence base to find high-leverage intervention
opportunities before narrowing down to any one of them.

## Why this exists

Work on `dzaleka-cost-model` produced a broad-to-narrow situation analysis
for Dzaleka Refugee Camp, Malawi (`docs/cases/dzaleka.md` here) — a
sector-level Theory of Change evidence base covering legal/policy, funding,
disaster risk, and protection pathways, sourced and dated throughout.

Fraternity generalizes that method and applies it across multiple
crises/camps. The goal right now is **breadth, not depth**: gather
comparable situation data across several sites so that patterns, structural
levers, and funding/protection gaps can be compared side by side. Once a
comparison across cases surfaces a genuine opportunity — a lever that is
high-leverage, tractable, and neglected relative to the others — we narrow
down and go deep on that one.

**Current phase: gathering information. Do not narrow yet.**

## Structure

- `CONCEPT.md` — the reusable research methodology (the four-pathway
  framework, sourcing discipline, output shape).
- `docs/cases/` — one file per crisis/camp, each following the same
  structure so they stay comparable.
- `docs/comparison.md` (once ≥3 cases exist) — cross-case comparison and
  candidate opportunity list.

## Sourcing discipline

Every figure keeps its original source, date, and reporting period. Numbers
that diverge across sources are not silently reconciled — the divergence
itself is often informative (reporting-period lag, methodology differences,
contested figures). Always check the date attached to a figure before using
it comparatively.
